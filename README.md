## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte de um desafio do curso Softjr. O objetivo era criar uma Landing Page utilizando HTML e CSS, aplicando conceitos de estruturação e estilização.

## 🛠️ Tecnologias
<li>HTML5: Para estruturação e organização do conteúdo.</li>
<li>CSS3: Para estilização</li>
